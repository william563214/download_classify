# 隱私政策

**生效日期**：2026-06-15

## 概述

「下載分類助手」（以下稱「本擴充功能」）尊重您的隱私。本政策說明我們如何處理資料。

## 資料收集

本擴充功能**不會**收集、傳輸或出售任何個人資料至外部伺服器。下載的檔案僅由瀏覽器存於您本機磁碟；本擴充功能不會上傳這些檔案。

## 本機儲存

以下資料僅儲存於您本機瀏覽器中。本擴充功能**不使用** `chrome.storage.sync`（不會因瀏覽器帳戶而把設定或紀錄同步到雲端）。`storage` 權限僅用於本機的 `local`／`session` 區域，不等於上傳使用者下載內容。

| 資料 | 儲存位置 | 用途 |
|---|---|---|
| 分類規則與設定 | `chrome.storage.local` | 網站分類、自定義規則、檔名與歸因設定 |
| 下載紀錄索引 | IndexedDB | 最近下載、統計、詢問頁資料 |
| 外連點擊暫存 | `chrome.storage.session` | 歸因候選（有效期限可設定） |
| 分頁導覽脈絡 | `chrome.storage.session` | 下載來源解析與歸因候選 |
| 歸因候選清單 | `chrome.storage.session` | 歸因詢問網站下載完成時的選項 |
| 已略過詢問的下載 ID | `chrome.storage.session` | 避免重複彈窗 |

## 歸因與隱私

- **平常下載**：以當前分頁或 referrer 為來源，不自動套用跨站 A→B 歸因
- **歸因詢問**：僅在設定中的網盤站下載完成後，顯示候選來源供您選擇
- **確認後**：才將選定來源寫入本機下載紀錄
- **檔案位置**：確認歸因或儲存分類規則不會搬移已下載檔案
- **分類與歸因**：分類決定資料夾路徑；歸因決定來源紀錄，兩者分開處理

## 權限用途

與 `manifest.json` 一致：

| 權限 | 用途 |
|---|---|
| `downloads` | 攔截下載並建議存檔路徑與檔名；歷史匯入時搜尋本機下載清單 |
| `storage` | 本機儲存規則與暫存脈絡（`local` + `session`；不用 `sync`） |
| `tabs` | 取得下載分頁與 opener 資訊 |
| `webNavigation` | 記錄分頁導覽以輔助來源解析 |
| `windows` | 開啟分類與歸因詢問視窗 |
| `<all_urls>` | Content Script 記錄外連點擊（不修改網頁） |

## 第三方服務

本擴充功能不使用任何第三方分析或追蹤服務。

## 資料刪除

解除安裝本擴充功能後，瀏覽器會清除相關儲存資料。您亦可於設定頁匯出後手動清除規則。

## 聯絡方式

如有疑問，請透過專案儲存庫提出 issue。
